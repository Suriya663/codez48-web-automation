Install Codez48 CLI

Latest v1.3.0
1

Install Node.js

Codez48 CLI requires Node.js and npm. Verify your installation by running these commands in your terminal:

node -v
npm -v
2

Install CLI Globally

Run this command to install Codez48 CLI globally:

npm install -g codez48-cli
3

Run Codez48 & Local Setup

After installation, launch the CLI:

codez48
Universal Automation Agent

Codez48 Pilot

Codez48 Pilot is the natural-language automation agent inside the Codez48 CLI. Describe what you want to accomplish, and Pilot understands the goal, inspects the required application or website, performs actions, verifies the result, and continues through multi-step workflows.

AI Chat (codez48 ai)

Conversational AI designed for questions, answering queries, code generation, and live brainstorming.

Pilot (codez48 pilot)

Goal-driven computer automation agent that operates real applications, creates files, builds projects, and executes workflows.

What Can Pilot Do?

🌐 Browser Automation

Live DOM, OCR, and visual element interaction.

💻 VS Code & IDE

Project creation, code editing, and execution.

🗂️ File & Folders

TXT, MD, JSON, CSV, and code file management.

📊 Excel Spreadsheets

Data workbooks, tables, and formula calculations.

📝 Word Documents

Professional reports, notes, and documentation.

📽️ PowerPoint Presentations

Structured slides, titles, and bullet points.

⚙️ Terminal Automation

Command execution, package installation, and logs.

📱 Android Projects

SDK auto-discovery, Gradle wrapper, and APK builds.

🔄 Cross-App Workflows

Seamlessly moves between browser, VS Code, and terminal.
