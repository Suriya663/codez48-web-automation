Quick Start Guide

Latest v1.1.0
1

Install Node.js

Ensure you have Node.js v18 or later installed. Verify with:

node -v
2

Install Codez48 CLI

Install the official package globally on your system:

npm install -g codez48-cli
3

Login to Account

Authenticate using your merchant credentials:

codez48 login

Interactive password entry is secure and masked.

Product Management

Control your digital storefront inventory with simple commands.

List Products

Interactive
codez48 list-products

Add New Product

Wizard
codez48 add-product

Free users can publish up to 4 products during their trial period.

Update & Delete

codez48 update-product
codez48 delete-product

AI Chat Interface

Start an interactive, contextual conversation with Codez48 AI directly from your terminal. Get instant help with products, code, or business strategy.

codez48 ai

Interactive Conversation

Once activated, the session remains open. You can ask multiple questions in sequence. Press Ctrl+C anytime to exit the chat.

Business Tools Hub

Tools Suite

Access the core command for all business utilities:

codez48 tools

Automation Sentinel

codez48 tools automation

Push Notifications

codez48 tools notifications

Mail Automation

Local Development

For developers contributing to the CLI or testing from source, you can run commands directly using Node.js without global installation.

node cli.js login
node cli.js tools list

Note: Development mode requires the CLI source folder and installed local dependencies.
